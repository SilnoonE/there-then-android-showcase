# 검증 범위

기준일: 2026-10-27.

## 원본 웹 작업본

자동 검사 13개가 통과했습니다. 다음 내용을 포함합니다.

- 이전 앨범 형식 읽기와 사진 포함 ZIP 왕복
- 잘못된 파일 경로와 누락된 사진 거부
- 선택 공유에서 이름·메모·위치를 기본 제외
- 독립 HTML의 문자열 처리, 내장 사진, 실행 스크립트 제외
- 파일 추가 시 기록·동행·사진 연결 유지
- 삭제 뒤에도 다른 기록이 참조하는 사진 보존
- 지난 오늘·윤년·다음 기념일 판단
- 인원·총예산·가능 시간을 고려한 약속, 가상 샘플 후보 제외

이 검사는 공개 저장소에 제품 전체 소스가 들어 있다는 의미가 아닙니다. 원본 웹 작업본의 검증 결과를 요약한 것입니다.

## 실제 브라우저

사진 입력, 기록 저장과 새로고침 후 보존, ZIP 다운로드·재불러오기·기존 앨범에 추가를 확인했습니다. HTML 공유 파일을 내려받아 선택 기록과 사진을 포함하고 개인 메모를 기본 제외하는지 확인했습니다.

약속 생성·확정, 캡슐 봉인과 목록 표시, 상세에서 편집으로 전환한 뒤 사진 추가·재저장을 확인했습니다. 390px 모바일 화면에서는 가로 넘침 없이 메뉴와 기록 카드가 표시됐습니다.

## 배포와 제품 검증의 구분

비공개 정적 배포의 성공과 소유자 로그인 화면을 확인했습니다. 로그인 이후 호스팅 환경에서의 실사용 기능 검증은 아직 하지 않았습니다. 기능 검사는 동일한 소스의 로컬 환경에서 수행했습니다.

실제 휴대폰·다른 브라우저·저장 공간 부족·대량 사진 등은 추가 확인 범위입니다. 현재 결과가 모든 환경의 동작을 보장하지 않습니다.

## 이 폴더의 공개 예제

공개 예제는 공유 필드 선택과 문자열 처리만 일반화했습니다. Node.js에서 아래와 같이 실행하면 기본 비공개 선택, 선택적 포함, 원본 보존, 문자열 처리의 자체 검사를 확인할 수 있습니다.

```sh
node web-showcase/examples/public-sharing.mjs
```

이 자체 검사는 원본 웹의 13개 검사와 별개이며 실제 ZIP 처리·IndexedDB·지도·호스팅을 검증하지 않습니다.
