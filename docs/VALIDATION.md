# 검증 범위

## 공개 예제

2026-10-27에 공개용 Kotlin 파일을 JVM으로 컴파일하고 `main`의 자체 검사를 실행했습니다.

- 동행별 필터와 없는 식별자
- 별명이 바뀐 뒤 식별자 연결 유지
- 좌표 미지정, 0도, 경계값, 한쪽 누락, 범위 초과, NaN, 무한대
- 이름·메모 포함 옵션 네 조합

Android 없이 실행하는 예제 검사입니다. 실제 지도 표시, 공유받는 앱의 동작, Android 파일 권한이나 사진 백업 전체를 검증하는 테스트는 아닙니다.

## 원본 앱과의 구분

원본 프로젝트에는 저장소 및 UI 흐름을 다루는 Android 계측 테스트가 있습니다. 이번 공개 작업은 구조를 읽고 공개 예제를 작성하는 작업이며, 원본 앱의 전체 릴리스 빌드와 기기 테스트를 새로 실행한 것은 아닙니다.

다른 기기에서의 지도 검색, 위치 권한 거부, 대량 사진, 백업 중 저장 공간 부족 등은 제품 검증에서 별도로 확인해야 합니다.

## 공개 전 점검

허용 목록으로 구성한 문서·예제만 새 저장소에 넣었습니다. 원본 프로젝트의 Git 이력·설정·빌드 산출물은 가져오지 않았습니다. 공개 파일에서 비밀 키 형식, 광고 식별자, 로컬 사용자 경로, 서명 파일, 실제 데이터 포함 여부를 점검했습니다.
